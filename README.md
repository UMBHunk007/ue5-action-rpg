## 📖 About

This project is my hands-on implementation of the
[**Making an Action RPG in Unreal Engine 5**](https://www.youtube.com/playlist?list=PL4G2bSPE_8une09Cb6vlKpYdakXK405WB)
playlist by **Ryan Laley** (11 videos). I'm building it step by step to learn the engine's gameplay framework and to practice
combat, character, and RPG system design.

> **Credit:** The structure, concepts, and original implementation come from Ryan Laley's tutorial.
> This repository is a learning project and is not an original design.

## 🚀 Getting Started

### Prerequisites

- Unreal Engine 5.[x] installed via the Epic Games Launcher
- [Visual Studio 2022 with "Game development with C++" workload, if using C++]
- Git (and Git LFS for large assets)

### Run the project

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
```

1. Right-click the `.uproject` file → **Generate Visual Studio project files** (C++ only).
2. Open the `.uproject` file with Unreal Engine 5.
3. Press **Play** in the editor.
